# 行列輸入法・網頁版

原 Python + Win32 Hook 版本移植而成的網頁版行列輸入法，保留原本的組字狀態機與虛擬鍵盤點擊組字邏輯，可直接在瀏覽器中用實體鍵盤或畫面上的虛擬鍵盤輸入。

## 基本操作

點一下輸入框，用實體鍵盤或下方虛擬鍵盤開始輸入字根。

- 拆碼唯一對應一字時，會直接送出，不需要再按任何確認鍵。
- 拆碼對應多個候選字時：
  - 按 **空白鍵**：送出目前排在第一位的候選字。
  - 按 **數字鍵 1～9、0**：直接指定候選字清單中對應位置的字（`0` 對應第 10 個）。
  - 候選字超過一頁（10 個）時，空白鍵改為「下一頁」，循環翻頁（最後一頁再按空白鍵會回到第一頁）；這種情況下無法用空白鍵送字，只能用數字鍵挑選，或用 **上／下方向鍵** 翻頁。
- **Esc**：清空目前正在輸入的字根。
- **Backspace**：逐一刪除字根；字根刪完後繼續按則刪除輸出框中已送出的文字。
- 游標右下角會即時浮出提示視窗，顯示目前打的字根與候選字（含頁碼）；透過萬用字元、同音字或注音模式選出的字送出後，會改成直列顯示該字所有標準拆碼。

## 字根鍵盤與拆碼規則

以標準鍵盤字母／符號鍵對應行列字根符號（畫面下方的虛擬鍵盤可對照鍵位小標籤），依 1～4 碼組字規則查出候選字：

| 拆碼長度 | 對應字庫 | 說明 |
|---|---|---|
| 1 碼 | `group3`（一級簡碼） | 極少數最常用字的快速鍵 |
| 2 碼 | `group1`（二級簡碼） | 次常用字的快速鍵 |
| 1 碼（展開後） | `group4`（一碼字） | 該碼實際收錄的完整候選字清單 |
| 2 碼（展開後） | `group2`（特別碼） | 該碼實際收錄的完整候選字清單 |
| 3～4 碼 | `group5` | 一般字 |
| 3～5 碼 | `group7` | 行列詞庫（含使用者自訂匯入） |
| `w0`～`w9` / `hg0`～`hg9` | `group6` | 行列符號表（符號選單索引，不是拼碼，浮動視窗不顯示「拆碼」那一行） |

> `group3`／`group1`（一、二級簡碼）只是**精簡對照表**，只收錄少量常用字快速鍵，不等於「這個拆碼底下所有同碼字」的完整集合；完整集合要看空白鍵展開後的 `group4`／`group2`（見〔簡碼展開即打即選〕）。

## 候選字送字規則

- 唯一候選字：按空白鍵直接送出。
- 多個候選字：空白鍵送第一位；數字鍵指定任一位。
- 候選字超過 10 個（一頁）：空白鍵變成翻頁鍵，需用數字鍵送字。

## 特殊查詢模式

### 萬用字元查詢

- `[` `*`：代表一個以上未知碼。
- `]` `?`：代表恰好一個未知碼。
- 範例：`3v[0-` 會列出「活／浴／滴」；`3v]0-` 會列出「沼／沾／沽」。
- 真的比對到候選字之後，浮動視窗會把 `[` `*` 顯示成「＊」、`]` `?` 顯示成「？」，畫面左上角印章同步顯示「萬」；比對到之前維持顯示原始符號、印章也不提早切換。
- 選出的字送出時，會在游標右下角浮出提示視窗，直列顯示它所有對應的字根碼。

### 同音字模式

- 觸發鍵：`'`（單引號）。
- 在**輸入框沒有任何字根**時按一下 `'`：先只是把 `'` 接上去，還不決定要進哪個模式；緊接著打其他任何鍵（`;` 除外）才視為確認進入同音字模式，印章變成「同」。
- 流程：輸入拆碼選出一個字 → 按空白鍵自動列出所有同音字（不含原字本身）→ 數字鍵選出想要的字送出，同時浮出提示視窗直列顯示這個字的所有標準拆碼，印章回到「中」。
- 注意：`'` 同時也是內建詞庫的慣用字尾，差別在於按下當下**是否已有正在輸入的字根**——沒有字根時才會觸發同音字判定，字根後面加 `'` 是叫出詞語，兩者不衝突。

### 注音模式

- 觸發鍵：`''`（連續兩個單引號，須在輸入框沒有字根時輸入）。
- 進入後印章變成「注」，虛擬鍵盤鍵位小標籤同步換成注音符號。
- 改用標準注音鍵盤：數字鍵、`, . / - ;` 都改為注音符號／聲調鍵，空白鍵＝一聲；音節還沒打完（查無候選字）之前不能選字，音節打完、真的查到候選字之後才能用空白鍵、數字鍵照常選字。
- 只查同音字反查表 `group8`（跟同音字模式共用同一份字庫）。
- 跟同音字、萬用字元一樣是**一次性**模式：選字送出的同時自動離開，印章與鍵位標籤立即換回原狀；還沒選字前想放棄，可打 `,,t` 或按 `Esc` 提前退出。

## 詞庫與自訂匯入

- 內建示範詞庫，例如 `xkie'`（以前）：打完字根碼加上慣用字尾 `'` 即可叫出詞語；字尾 `'` 可加可不加，若加上且只查到一個詞，會直接送出、不用按空白鍵。
- 點工具列「**匯入 array.box**」按鈕，可選擇本機 `.box`／`.txt` 檔（UTF-8 純文字，每行格式為「字根碼　詞」）擴充詞庫。
- 每次匯入完成後，快打模式用的拆碼反查索引表會自動重新建立。

---

## 快打模式（,,sp）

- 進入：在輸入框**沒有字根**時依序打 `,` `,` `s` `p`（即 `,,sp`）。
- 離開：打 `,,t`。
- 印章：進入後從「中」變成「快」，離開後變回「中」。
- 行為：進入後照平常方式拆碼、選字；選字送出當下會判斷「這次實際打的拆碼」是不是這個字最短拆碼的其中一組：
  - 不是 → 先在游標旁直列顯示這個字所有的最短拆碼，再送出這個字。
  - 是（或這個字本來就只有唯一寫法、或它是詞句）→ 直接送字，不彈提示。
- 快打模式**不是一次性**的，會持續套用到之後每個字，直到打 `,,t` 才切換回原本打法。

## 兩字詞自動組合模式

`,,ai` 與 `,,ia` 是兩套**互斥**（同一時間只會處在其中一種）、且都**不是一次性**（需明確打 `,,t` 才離開）的組詞模式，印章進入後都會顯示「詞」。

### ,,ai：不限碼長、打完才結算

- 進入：`,,ai`；離開：`,,t`。
- 每選一個字先**不送字**，暫存進緩衝區；游標旁會即時顯示目前已選的這幾個字，如果剛好湊出詞庫（`group7`）收錄的詞，會直接顯示比對到的那個詞；如果目前湊不出詞，會顯示「已比對到的最長一段詞」加上後面還沒湊成新詞的字，依序接在後面（不會整個退回顯示成一串個別字元，也不會把新打的字藏起來看不到）。
- **連續按兩個空白**（中間沒有再打字根）＝這個詞打完了，開始結算：
  - 只選了一個字：直接送出。
  - 選了兩個字以上：用每一步「所有同碼候選字」互相排列組合，去比對「打了幾個字就找幾字詞」的詞庫——
    - 剛好比對到一個詞 → 直接送出。
    - 比對到一個以上 → 列出來，用數字鍵或空白鍵挑選。
    - 一個都比對不到 → 退回依序送出原本各自選中的那幾個字，不會平白消失。
- 反悔最後一個字：按 **Backspace** 收回緩衝區最後一筆。
- 整個放棄：按 **Esc** 或切換中英文，會把暫存的字直接照原樣送出後再重置。
- 打完一個拆碼（1 碼，命中 `group3`）按空白鍵、`group4` 有一個以上候選字時，或打完兩個拆碼（2 碼，命中 `group1`）按空白鍵、`group2` 有一個以上候選字時：會展開顯示對應的完整候選字清單（`group4`／`group2`），同時組詞浮動視窗會先預覽清單中排在第一位的候選字。
- 「二／一」切到「一」時：上述展開情境第一下空白鍵會直接把整組候選字暫存進緩衝區，不需要像「二」模式那樣按第二次空白鍵才存入。
- **最長碼長限制在四碼**：,,ai 模式下每個字最多只能打四個字根，打滿後不會再接上第五碼，避免誤打到只給整詞用的五碼詞庫項目；離開 ,,ai 模式後不受此限制。

### ,,ia：固定兩字、邊打邊確認

- 進入：`,,ia`；離開：`,,t`。
- 跟 `,,ai`「打完整個詞才結算」不同，`,,ia` 是**固定兩個字、邊打邊確認**：
  - **打第一個字**：不論這次拆碼查到一個還是多個候選字，第一下空白鍵一律只負責「列出」對應的完整候選字清單（1 碼展開 `group4`、2 碼展開 `group2`，不是精簡表 `group3`／`group1`），不送字；組詞浮動視窗同時會預覽清單中排在第一位的候選字。接著：
    - 再按一次空白鍵、或直接打數字鍵挑選 → 這個字要單獨輸入，直接照原樣送出，不進入兩字詞組合。
    - 改打三十個標準字根中的任一個 → 要繼續組詞：這個字先暫存起來，字根本身保留下來成為第二個字的第一個拆碼。
  - **打第二個字**：每打一碼，就即時用「第一個字＋這次拆碼查到的每個候選字」比對兩字詞詞庫（`group7`，只看剛好兩個字的詞），比對到的詞會即時顯示在浮動視窗。按空白鍵時：
    - 剛好比對到一個詞 → 直接送出，狀態全部清空。
    - 比對到一個以上 → 先凍結候選詞清單，等打任一標準字根（同時成為下一個字的第一個拆碼）、按數字鍵、或再按一次空白鍵確認。
    - 完全比對不到 → 不受影響，照一般選字流程選出第二個字，直接跟第一個字組合送出（不要求一定要是詞庫收錄的詞）。
- 反悔：已選出第一個字、還沒打第二個字拆碼時，按 **Backspace** 收回第一個字；整個放棄按 **Esc** 或切換中英文，會把暫存內容照原樣送出後再重置。
- 「二／一」切到「一」時的規則、最長碼長限制在四碼：與 `,,ai` 相同。

## 簡碼展開即打即選

打一個字根（1 碼）命中一級簡碼 `group3` 並按空白鍵後，若對應的 `group4`（一碼字）有一個以上候選字，會展開顯示 `group4` 候選字清單；打兩個字根（2 碼）命中二級簡碼 `group1` 並按空白鍵後，若對應的 `group2`（特別碼）有一個以上候選字，會展開顯示 `group2` 候選字清單。

在這兩種展開狀態下，接著打**任何一個標準字根**（`a`～`z` 或 `, . / ;`）都視同按空白鍵，直接送出目前排在第一位的候選字；這個字根本身不會丟棄，會直接成為下一個字的第一個字根，繼續組字，不需要重新打過。仍可用數字鍵 1～9、0 直接指定其他候選字。此規則只作用在一般組字流程，不影響同音字模式。

## 三～五碼同碼字送字規則（二／一按鈕）

拆碼長度落在三到五碼（對應 `group5` 三、四碼字，或 `group7` 詞庫）時：

- 若這組碼只有唯一候選字（沒有同碼字），按一下空白鍵就直接送出，不受下面設定影響。
- 若這組碼有一個以上候選字（同碼字），依工具列「**二／一**」按鈕設定決定送字方式：

| 設定 | 行為 |
|---|---|
| **二**（預設） | 第一下空白鍵先不送字，只是先確認一下；接著再按一次空白鍵、或直接打任一個標準字根，才會送出目前排在第一位的候選字（打字根送字時，這個字根本身不丟棄，直接成為下一個字的第一個字根）。 |
| **一** | 取消「第一下空白先不送字」的確認機制，按一下空白鍵就直接送出第一位候選字，跟唯一候選字時的行為一樣。切到「一」時還會額外套用：①若 `group4` 的候選字集合剛好是 `group3` 在相同數字位置上的子集合，空白鍵不展開 `group4`，直接送出第一候選字；②若 `group2` 的候選字集合剛好是 `group1` 在相同數字位置上的子集合，空白鍵不展開 `group2`，直接送出第一候選字。這兩個條件只在「一」模式下生效。 |

| `group8` | 同音字反查表／注音模式查詢字庫 | 兩種用途共用同一份資料 |
| `group9` | 完整拆碼對照表 | 供「所有拆法」提示切到「10」時查詢 |

`array.box` 格式：UTF-8 純文字，每行 `字根碼␠詞`（碼與詞之間以空白分隔），匯入後自動併入 `group7` 並重建相關索引（快打反查索引、詞庫比對用的分字數集合等）。
