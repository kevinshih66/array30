# 行列輸入法網頁版

純前端（單一 HTML 檔，無需安裝、無需伺服器）的行列輸入法模擬器，支援完整鍵盤字根組字、萬用字元查詢、同音字反查、注音查字、自訂詞庫匯入，以及兩種「多字詞自動組合」輸入模式。

打開 `行列輸入法網頁版_加入ia兩字詞組合功能.html` 即可在瀏覽器中使用，畫面右上角「功能說明」按鈕內也有完整的操作說明。

---

## 功能特色

- **行列字根輸入**：以鍵盤字母對應字根符號，依 1～5 碼組字規則查出對應候選字。
- **虛擬鍵盤**：可用滑鼠點擊操作，與實體鍵盤共用同一套組字邏輯；進入注音模式時鍵位小標籤會暫時換成注音符號。
- **游標浮動提示窗**：打字時即時顯示目前字根與候選字（含頁碼）；透過萬用字元、同音字或注音模式選出的字，送出後改為直列顯示該字所有標準拆碼。
- **中／英文切換**：`F12`、`Ctrl+空白鍵`，或單獨點一下 `Ctrl` 鍵。
- **半形／全形切換**：`Shift+空白鍵`。
- **萬用字元查詢**：`[` `*` 代表一個以上未知碼；`]` `?` 代表恰好一個未知碼。
- **同音字模式**：按 `'` 進入，選字後自動列出同音字。
- **注音模式**：按 `''`（連續兩個單引號）進入，改用標準注音鍵盤打注音選字。
- **內建詞庫／自訂詞庫**：內建示範詞庫，可匯入自訂 `array.box`（UTF-8 純文字，每行「字根碼 詞」）擴充。
- **快打模式**（`,,sp`）：送字時若這次拆碼不是該字最短拆碼，會先提示最短拆碼再送字。
- **`,,ai` 多字詞自動組合模式**：連續選字暫存，直到連按兩個空白才結算，排列組合比對詞庫。
- **`,,ia` 固定兩字詞自動組合模式**：邊打邊即時比對兩字詞詞庫，不需要打完整個詞才結算。
- **簡碼展開即打即選**：一級簡碼／二級簡碼展開候選清單後，接著打任一標準字根即視同按空白鍵送字。
- **兩個空白鍵送字規則**：可用工具列「二／一」按鈕切換要不要多一次空白鍵確認。
- **候選字超過一頁**：空白鍵改當「下一頁」，需用數字鍵 1～9、0 才能送字。
- **編輯工具列**：切換中英文／全半形／字級／複製內容／顯示或隱藏虛擬鍵盤與提示區／查看說明。

## 使用方式

### 1. 開始輸入
點一下輸入框，用實體鍵盤或虛擬鍵盤輸入字根。拆碼唯一對應一字時直接送出；有多個候選字時，按空白鍵送出排第一位的候選字，或按數字鍵 1～9、0 直接挑選對應位置的候選字。**候選字超過一頁（10 個）時，空白鍵會改成「下一頁」**，這時無法用空白鍵送字，只能用數字鍵挑選；也可用上／下方向鍵翻頁。按 `Esc` 清空目前輸入，按 `Backspace` 逐一刪除字根或已輸出的文字。

### 2. 切換中文／英文
按 `F12`，或按住 `Ctrl` 同時按空白鍵，或單獨輕點一下 `Ctrl` 鍵。

### 3. 切換半形／全形
按 `Shift + 空白鍵`。

### 4. 萬用字元查詢
`[` `*` 代表一個以上未知碼，`]` `?` 代表恰好一個未知碼。真的比對到候選字後，浮動視窗會把符號換顯成「＊」「？」，畫面左上角印章同步顯示「萬」。

### 5. 同音字模式
在輸入框沒有任何字根時按 `'`：緊接著打其他任何鍵（不含 `;`）即視同確認進入同音字模式，印章變成「同」。選出一個字 → 按空白鍵列出所有同音字 → 數字鍵選字送出，印章回到「中」。

> 注意：`'` 同時也是內建詞庫的慣用字尾，差別在按下當下是否已有輸入中的字根——沒字根時才會觸發同音字判定。

### 6. 注音模式
在輸入框沒有任何字根時打 `''`（連續兩個單引號）才會確認進入注音模式，印章變成「注」，虛擬鍵盤鍵位同步換成注音符號。此時數字鍵、`, . / - ;` 都改當注音符號／聲調鍵（空白鍵＝一聲）。音節打完、查到候選字後才能選字送出，送出後自動離開注音模式。中途想放棄可打 `,,t` 或按 `Esc`。

### 7. 內建詞庫與自訂詞庫
打完字根碼加上慣用字尾 `'` 即可叫出詞語（若只有一個詞會直接送出，不用按空白鍵）。可點「匯入 array.box」按鈕匯入自訂詞庫，匯入完成後快打模式用的拆碼反查索引表也會自動重建。

### 8. 快打模式
輸入框沒有字根時依序打 `,,sp` 進入，印章從「中」變「快」。之後每上一個字，若這次實際打的拆碼不是該字最短拆碼之一，會先直列顯示所有最短拆碼再送字；打 `,,t` 離開。

### 8b. `,,ai` 兩字詞自動組合模式
輸入框沒有字根時依序打 `,,ai` 進入，印章變「詞」。之後每選一個字先暫存、不送出（游標旁即時顯示已選字，湊到詞庫詞時會直接顯示該詞），**連續按兩個空白**（中間沒再打字根）才結算：

- 只選了一個字 → 直接送出該字。
- 選了兩個字以上 → 用每一步「所有同碼候選字」排列組合，去比對「打了幾個字就找幾字詞」的詞庫（`group7`）：
  - 剛好比對到一個詞 → 直接送出。
  - 比對到一個以上 → 列出來讓你挑（見下方「候選詞選字方式」）。
  - 一個都比對不到 → 退回依序送出你原本各自選中的那幾個字。

中途按 `Backspace` 收回暫存區最後一筆；按 `Esc` 或切換中英文會把暫存的字照原樣送出後重置。打 `,,t` 離開。

**候選詞選字方式（`,,ai` 結算比對到一個以上詞時）：**
- 數字鍵 1～9、0：直接指定清單中對應位置的詞。
- 空白鍵：送出目前排第一位的詞（多頁時先翻頁）。
- **打三十個標準字根（`a`～`z` 或 `, . / ;`）中的任一個**：一律視同選第一位的候選詞，直接送出；這個字根本身不丟棄，會保留下來成為下一個字的第一個拆碼，可以無縫接著打。此規則跟「二／一」切換鍵設定無關，兩種模式下都適用。

**「二／一」切到「一」時的額外規則**：`,,ai` 模式下，若打完一碼命中一級簡碼（`group3`）按空白鍵時 `group4` 有一個以上候選字，或打完兩碼命中二級簡碼（`group1`）按空白鍵時 `group2` 有一個以上候選字，只要切到「一」，第一下空白鍵就會直接把候選字集合（`group4` 或 `group2`）暫存進去，不用像「二」模式那樣再按第二次空白鍵。

**最長碼長限制在四碼**：`,,ai` 模式下每個字最多打四個字根，避免誤觸完整五碼詞庫項目。離開模式後不受此限制。

### 8c. `,,ia` 固定兩字詞自動組合模式
輸入框沒有字根時依序打 `,,ia` 進入，印章同樣變「詞」（跟 `,,ai` 互斥，同一時間只會處在其中一種）。跟 `,,ai`「打完整個詞才結算」不同，`,,ia` 是「固定兩個字、邊打邊確認」：

- **打第一個字**：不論查到一個還是多個候選字，第一下空白鍵一律只負責「列出」候選字、不送字。接著：
  - 再按一次空白鍵、或直接打數字鍵 → 代表單獨輸入，直接送出，不進入組詞。
  - 改打任一標準字根 → 代表繼續組詞，這個字先暫存，字根保留下來成為第二個字的第一個拆碼。
- **打第二個字**：每打一碼都即時用「第一個字＋這次拆碼查到的每個候選字」比對兩字詞詞庫（`group7`，只看剛好兩個字的詞），比對結果即時顯示在游標旁。按空白鍵時：
  - 剛好比對到一個詞 → 直接送出，整個狀態清空。
  - 比對到一個以上 → 凍結候選詞清單，等你打任一標準字根、按數字鍵、或再按一次空白鍵確認送出。
  - 完全比對不到 → 退回一般選字流程，選出第二個字後直接跟第一個字組合送出。

中途按 `Backspace` 可收回已選的第一個字；按 `Esc` 或切換中英文會把暫存內容照原樣送出後重置。打 `,,t` 離開。

「二／一」切到「一」時的額外規則、最長碼長限制在四碼，跟 `,,ai` 完全相同。

### 9. 簡碼展開即打即選（一級簡碼／二級簡碼）
打一碼命中一級簡碼（`group3`）並按空白鍵後，若 `group4` 有一個以上候選字，會展開清單；打兩碼命中二級簡碼（`group1`）並按空白鍵後，若 `group2` 有一個以上候選字，也會展開清單。展開狀態下接著打任一標準字根，一律視同按空白鍵送出排第一位的候選字，字根本身保留下來成為下一個字的第一碼。仍可用數字鍵直接指定其他候選字。此規則不影響同音字模式。

### 10. 三～五碼同碼字送字規則（二／一按鈕）
拆碼長度三～五碼（`group5` 三四碼字、`group7` 詞庫）時：
- 只有唯一候選字 → 按空白鍵直接送出，不受下方設定影響。
- 有一個以上候選字（同碼字）→ 依「二／一」按鈕設定：
  - **二**（預設）：第一下空白鍵先不送字，接著再按一次空白鍵、或直接打任一標準字根送出排第一位的候選字。
  - **一**：取消確認機制，按一下空白鍵就直接送出排第一位的候選字。

## 近期修正紀錄

1. **`,,ai`／`,,ia` 組詞模式在「二／一」切到「一」時的候選字污染問題**
   一碼字（`group4`）／兩碼字（`group2`）在空白鍵送字時，若剛好符合「候選字集合是一級簡碼（`group3`）／二級簡碼（`group1`）在相同位置上的子集合」這個捷徑條件，原本會把 `group3`／`group1` 的**完整**候選字清單（而不是限制在 `group4`／`group2`）存進暫存區，導致之後跟其他字排列組合比對詞庫時，誤用到使用者這次其實選不到的候選字，組出不該出現的詞（例如把「獎」的一碼候選字誤混入同碼的「將」，跟下一個字組出錯誤的詞）。已修正為一律只用 `group4`／`group2` 的候選字集合，並且對「接著打字根視同送字」的續打路徑也套用同樣限制。
2. **`,,ai` 組詞結算後，候選詞一個以上時無法用字根鍵直接選字**
   原本詞庫比對到一個以上候選詞時，只能用數字鍵或空白鍵挑選，打其他標準字根會被直接吞掉。已比照 `,,ia` 既有的「打即選」規則，補上：打三十個標準字根中的任一個，一律視同選第一位候選詞直接送出，且該字根保留下來成為下一個字的第一個拆碼，可以無縫接續輸入。此修正對「二／一」切換鍵的兩種設定都適用。
3. **`,,ia` 第二個字用「打即選」續打方式送出時，沒有完整比對兩字詞詞庫**
   按空白鍵送出第二個字時，本來就會用「第一個字全部候選字 × 第二個字全部候選字」完整比對兩字詞詞庫（剛好一個詞才直接送出，一個以上進入 `combo2WaitConfirm` 讓使用者按數字鍵挑選）。但如果第二個字是透過簡碼展開後「不按空白鍵、直接接著打下一個標準字根」的續打方式送出，原本只會回頭檢查第一個字有沒有其他候選字能配對（`resolveCombo2Char1`），沒有检查第二個字本身是否選對候選字，可能把同碼字（例如「人」／「入」）誤送成詞庫沒有收錄、或不是使用者原意的組合（例如打「輸」＋「入」卻送出「輸人」）。已新增 `combo2FullMatches()`，讓所有「非明確按數字鍵挑選」的送字路徑都改用兩邊完整候選字集合比對詞庫，比對到一個以上一樣會凍結進入數字鍵確認狀態；仍會避開「group4／group2 查無候選字、退回用 group3／group1」這種來源不乾淨的情況，避免重新引入第 1 點的污染問題。使用者用數字鍵明確指定第二個字時，維持完全信任該選擇，不受影響。
